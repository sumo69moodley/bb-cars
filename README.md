# BB Cars Auto Body – website design preview

Homepage design for the new BB Cars Auto Body website (bbcars.co.za), prepared by iNCO Creative for review and approval.

- **Live preview:** https://sumo69moodley.github.io/bb-cars/
- **Manufacturer approvals view:** https://sumo69moodley.github.io/bb-cars/#approvals
- **WordPress theme:** `bbcars-theme.zip` – install under Appearance › Themes › Add New › Upload Theme. Setup notes are in the theme's README.txt.
